# 🎓 YieldPro – Educational Web Application

YieldPro is a web application developed as a **second-year Software Engineering group project**. The project combines an educational platform with an interactive chatbot to provide users with a more engaging learning experience.

The application was developed using **React.js** for the frontend and **Flask** for the backend, with Machine Learning techniques explored for the chatbot functionality.

## 📌 Project Overview

YieldPro aims to provide an interactive educational environment where users can access educational content and interact with a chatbot for additional assistance.

The project provided practical experience in:

* Full-stack web application development
* Frontend development with React.js
* Backend development with Flask
* Machine Learning integration
* API-based communication
* Team-based software development

## 🚀 Main Features

### 📚 Educational Blog

* Provides educational content through a web-based interface

* Designed to provide a user-friendly learning experience
